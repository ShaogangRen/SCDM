# SCDM

Research project webpage for **Scalable Causal Discovery in Nonlinear Temporal Systems with Meta-Learning** (NeurIPS 2026).

Website: https://shaogangren.github.io/SCDM/

Paper: https://openreview.net/forum?id=H2Bm4cicZc

This repository currently contains the project webpage. Research code will be added separately.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**, then Save.
The website is static HTML/CSS/JavaScript; no build step is required.

## Editing

Edit `content.js` for authors, text, benchmark values and citation, `index.html` for page structure,
and `academic.css` for the academic project-page layout. Figures are in `assets/`.
Use relative asset paths so the webpage works at `/SCDM/`.

Author homepages for Jingbo Wang and Kegeng Tang remain to be provided.
